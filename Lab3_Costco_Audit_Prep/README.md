# Costco Lab 3 audit preparation

This folder contains an offline fallback report for the saved COST data run and a blank human-audit worksheet. The report uses Costco's FY2026 10-K, its September 24, 2026 earnings release, and the saved peer facts for WMT, TGT, and BJ.

The worksheet has no AI marks. You must check the report against the source files by hand. The course says not to use AI for the marks. Do not submit the report as hand-audited until you complete the worksheet yourself.

## Contents

- `COST_fallback_report.md`: five-part fallback report. The live role call did not return a report.
- `COST_manual_audit.md`: evidence and values for your hand check. Marks are blank.
- `sources/`: saved COST filing texts, XBRL facts, and peer 10-K texts and facts.

The COST audit is separate from Checkpoint 1's required partner-pick report. The Checkpoint 1 submission package is in `Checkpoint1_Submission`.
